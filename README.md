# Justie

> 🗄️ **Archived learning project.** Built in 2017 while taking an introductory iOS course, kept as-is as a snapshot of where I started. It targets Swift 3 / iOS 10 and won't build in current Xcode without migration.

My very first iOS app (March 2017): two text fields, a button, and a label that shows their sum.

**What I learned:** Xcode and Interface Builder basics, `@IBOutlet` / `@IBAction`, and converting text input to numbers.

**Stack:** Swift 3 · UIKit · Storyboards · iOS 10.2
